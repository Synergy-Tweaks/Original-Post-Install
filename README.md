# SynergyOS Original Post Install

This is the original [SynergyOS](https://github.com/Synergy-Tweaks/SynergyOS) post-install folder, kept here as a backup in case something doesn't work in the toolkit.

Before [SynToolkit](https://github.com/Synergy-Tweaks/SynToolkit) existed, this folder was what was on your desktop for setting up a system after installing SynergyOS. It's a set of manual files and Configurations, split into numbered sections you'd work through in order.

## What's inside

- **1. GPU Install** — GPU driver setup
- **2. Configuration** — core post-install configuration
- **3. Optional Configuration** — extra tweaks that aren't required but nice to have
- **4. More Wallpapers** — additional wallpaper options
- **5. Synergy Support.url** — link to Kwan's Performance Hub Server

## Status

All of this is now handled inside SynToolkit, which replaced the manual process with an actual application. This repo is kept around as a fallback — if something in the toolkit isn't working right, these are the original manual steps you can use instead.
